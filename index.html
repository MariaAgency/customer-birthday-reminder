How to use (every Monday, about 5 minutes)
  1. Keep one Excel file with these columns: Customer Name, Company, Birthday, Phone, Email, Account Manager. Tap Get Excel template for a blank one. An optional Greeting Name column (for example "Dato' Lim") is used in the message instead of the full name.
  2. Tap Load Excel / CSV, check the columns, then tap Use this list. The list stays on this device, so next week you only reload it if the file changed.
  3. Orange cards are birthdays within 3 days: send these now. Pick a language, edit the message if you like.
  4. WhatsApp: tap Copy picture (or Save picture), then Open WhatsApp. The message is already typed; paste or attach the picture and press send. Email: tap Copy message and paste it, with the picture, into your email.
  5. After you send, tap Mark as sent. The card turns green so nobody in the team sends twice on this device.
  6. Tap Download PDF list to share the week's list with your team. Each customer has the picture and the message, ready to copy.
  7. Rows in Fix in your Excel are left out until you correct them. The app never guesses a birthday.
